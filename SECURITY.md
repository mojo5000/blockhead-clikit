# Security Policy

## Supported versions

The latest released version receives security fixes. Pin a released tag (see the
README) so you can upgrade deliberately.

## Reporting a vulnerability

Please report suspected vulnerabilities **privately** rather than opening a
public issue. Use GitHub's [private vulnerability
reporting](https://github.com/mojo5000/blockhead-clikit/security/advisories/new)
("Report a vulnerability" under the repository's **Security** tab).

Include a description, reproduction steps, and the affected version. You can
expect an initial response within a few days. Once a fix is available, it will
be released and the advisory published.
